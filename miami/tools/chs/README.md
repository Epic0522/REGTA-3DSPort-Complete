# Chinese text support (Vice City)

Experimental Simplified Chinese text for the Vice City port.

## What this is

This directory is a self-contained, optional pack:

- `TEXT/american.gxt` — the Vice City text table (4718 strings, ~75.7k characters,
  1960 distinct code points) taken from 无名汉化组's Chinese patch, redistributed by
  [Lzh102938/Revc_Chs](https://github.com/Lzh102938/Revc_Chs).
- `models/chsfont.a8` + `chsfont.map` — the glyph atlas and code point map
  generated by `miami/tools/gen_chs_font.py` from the strings above.
  One 1024x1024 page, 20x20 pixels per glyph (matching the height of the Latin
  font), 8-bit coverage stored on disk and expanded to an RGBA8 texture at boot.

The engine side (`miami/src/render/Font.cpp`) renders CJK code points from that
atlas inside `CFont::RenderFontBuffer()`, so menus, subtitles and HUD all use it.

## Enabling it

```sh
python3 miami/tools/apply_chs_text.py     # copies the pack into gamefiles/revc + refreshes the manifest
./scripts/build.sh revc
./scripts/setup-game.sh revc <game dir> <SD>/3ds   # now also installs models/chsfont.*
./scripts/install-3dsx.sh revc <SD>/3ds
```

The install validation (`common/3ds/InstallManifest.h`) pins the SHA-256 of every
curated override, so the manifest has to be regenerated whenever the text table
changes — that is what `apply_chs_text.py` does for you.

To go back to English:

```sh
python3 miami/tools/apply_chs_text.py --remove
./scripts/build.sh revc
```

## Regenerating the atlas

Only needed if the text table changes. Requires Pillow and a CJK font:

```sh
python3 miami/tools/gen_chs_font.py miami/tools/chs/TEXT/american.gxt \
    --outdir miami/tools/chs/models
```

By default it uses Noto Sans CJK (`/usr/share/fonts/noto-cjk/NotoSansCJK-Regular.ttc`);
pass `--font <path>` for a different face.

## Known limitations

- No automatic line breaking for CJK: lines wrap only where the source text has
  explicit breaks, so a few long mission briefings can run past the edge.
- The bold rendering pass is not applied to CJK glyphs.
- Code points above the BMP (rare in this translation) are not supported.
- The translation itself contains untranslated strings (~16% are still English),
  mostly proper nouns.
